# Meta Ad Spy Tool

A DTC intelligence platform for spying on Meta (Facebook/Instagram) ads.

## Repository

**GitHub:** https://github.com/carswqqqq1/README

**Branch:** `claude/meta-ad-spy-tool-vtxd4`

## Tech Stack

- **Framework:** Next.js
- **Database:** Turso (SQLite in the cloud)
- **Styling:** Tailwind CSS
- **Deployment:** Vercel

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/carswqqqq1/README
   cd README
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Copy the environment file and fill in your values:
   ```bash
   cp .env.example .env
   ```

4. Run the development server:
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) to view the app.

## Environment Variables

See `.env.example` for required variables.
